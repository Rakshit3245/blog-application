# Simple Blog Application with Django

This is a simple blog application built using **Django** with **SQLite3** as the database, **HTML** templates for rendering content, and **Bootstrap** for styling the frontend.

# Features

- **Create Blog Posts**: Users can create blog posts with a title, content, and an optional image.
- **View Blog Posts**: All blog posts are displayed on the homepage with their title, a brief excerpt, and the number of likes.
- **Blog Details Page**: Each blog post has a dedicated page where users can view the full content and additional details (e.g., the author's name, creation date).
- **Like Blog Posts**: Users can like a blog post, and the like count will be displayed on both the homepage and the blog details page.
- **Comment on Blog Posts**: Users can comment on individual blog posts. Comments will appear under the respective blog post.
- **Like Count Visibility**: The application shows the number of likes each post has received, visible on both the homepage and the blog detail page.
- **Responsive Frontend**: The application uses **Bootstrap** to make the frontend responsive, ensuring a seamless experience across devices.
- **Simple User Interface**: Clean, easy-to-navigate UI with Bootstrap styling for a modern, responsive design.
- **User Authentication (Optional)**: Users can sign up, log in, and manage their blog posts, likes, and comments.


## Requirements

- Python 3.x
- Django 4.x or higher
- SQLite3 (comes pre-installed with Django)
- Bootstrap (included in the HTML templates)
